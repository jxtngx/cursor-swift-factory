# Getting started

1. Open this repo in Cursor so `.cursor/` loads.
2. Run `@init-app`.
3. Answer platform: iOS, macOS, or Watch App.
4. If iOS, answer iPhone, iPad, or Universal.
5. Finish discovery. Approve the spec.
6. Then `@chief-architect` → `@swift-sme` → `@scrum-master` → `@run-ticket-plan`.

Do not scaffold Xcode in step 2.

You need Xcode on a Mac to build the walking skeleton. The factory still writes the spec anywhere.
